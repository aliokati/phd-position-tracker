# Funded PhD position tracker

This repository publishes a privacy-safe discovery dashboard at GitHub Pages. A GitHub Actions workflow scans the configured public feeds every three hours and refreshes `docs/positions.json` and the dashboard.

The workflow only gathers public position metadata. It does not contain the CV, email account, credentials, or application documents, and it never submits an application.

Every new row is marked `Discovered – verify`. Confirm the official listing, funding, deadline, Iranian-citizen eligibility, and research fit before applying.
